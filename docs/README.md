# Precentor's documents

The [README](../README.md) at the root of the repository is the place
to start: what Precentor is, how it works, how to run it and how it was
tested. These are the documents behind it. Some describe the app as it
is built and are kept up to date; others are plans I wrote before
building something, kept as a record of how the decisions were made.

## Current: the app as built

| Document | What it's for |
| -------- | ------------- |
| [`testing.md`](testing.md) | Every check and test with its result and the checker's own screenshots, the manual tests by feature, widths, browsers and devices, the bugs found and fixed, and the checks after each deploy |
| [`user_stories.md`](user_stories.md) | The user stories for each role, each with the page or feature that meets it |
| [`models_plan.md`](models_plan.md) | Each app's models, field by field, and why |
| [`erd.mmd`](erd.mmd) | The entity relationship diagram for all 23 tables, which GitHub draws |
| [`design_system.md`](design_system.md) | The CSS method (CUBE CSS), cascade layers, design tokens, type, and the liturgical accent |
| [`blocks_backlog.md`](blocks_backlog.md) | Each Block in the CSS, where the pattern was seen and why it became a Block |
| [`calendar_plan.md`](calendar_plan.md) | Ordo's two calendars and their order of precedence: the design, the sources, and how it was built and checked |
| [`acknowledgements.md`](acknowledgements.md) | Every outside source, what I took from it, and its licence |
| [`merge_record.md`](merge_record.md) | How the work since my first submission reached the live site on 10 November 2026, rehearsed first on a copy of the live data |
