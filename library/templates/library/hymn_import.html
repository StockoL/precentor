Import a list into {{ hymnal.name }}

If you already keep this book's numbers in a spreadsheet, you can bring them in at once instead of as each hymn is sung.

  1. Download the template.
  2. Fill it in, one hymn per row. Only the Number is needed; the first line, metre and tune help with suggestions and the pew sheet when you have them.
  3. Save it as a CSV, or in Google Sheets share it as Anyone with the link and copy the link.
  4. Choose the file, or paste the link, below and press Import.

Where {{ hymnal.short_name }} already has a number, nothing you've written for it changes: the list only fills in details that are blank. Afterwards you'll see what changed and can keep it or remove the whole import.
